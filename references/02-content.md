# 内容创作：选题、封面、标题

## 一、六种选题法

### 1. 对标账号选题法（起号必做）
1. 找 1–3 个对标账号
2. 筛出点赞前十的笔记
3. 分类汇总，做成账号爆款选题库
   - 集中在哪些话题？
   - 哪些关键词出现频率高？
   - 有哪些共性？

### 2. 长尾关键词裂变法
**长尾关键词** = 用户搜大关键词后，搜索框下拉延伸出来的细分词。

找法：
- **搜索页**：输入大关键词，下拉列表里全是系统根据真实搜索行为匹配的热词
- **搜索结果页**：点对应文字选项；排名靠前的笔记权重高、质量有保障，且会按时间热度更新，可持续关注
- **第三方工具**：5188 等长尾词工具

延伸维度：效果/场景、人群、事物。

### 3. 评论区选题法
去对标账号的爆款评论区看：
- 哪些词出现次数高？
- 用户在讨论什么？
- 看完笔记后还有什么疑问？（**这就是你的下一篇**）
- 在表达什么情绪？

典型信号：
- 大量要购买链接 → 物品吸引人，可做同类种草
- 表达情绪、争论观点 → 可切入个性化观点

### 4. 热点选题法
渠道：小红书 → 创作中心 → **笔记灵感**（每周更新各领域热门话题，每周必看）

三个判断：
- 速度够不够快（你对这个热点了解多少？创作难度多大？）
- 能不能满足用户需求
- 有没有差异化（独特观点 / 差异化角度）

### 5. 交叉选题法
把这些维度交叉组合：**领域 × 内容形式 × 时间 × 人群 × 价格**
例：AI 增长（领域）× 清单（形式）× 转行第一个月（时间）× 非技术背景（人群）

### 6. 系列选题法
- **固定栏目**：根据账号定位设更细分的垂直选题
- **固定时间**：每周/每月某天发某类主题（月度书单、本月开箱）
- **系列专题**：围绕一个大事件或时间节点做一串内容

## 二、搭建选题库

1. **对已有爆款做减法**——在爆款选题里筛出符合自己人设、能力、知识储备的
2. **搭建自己的知识体系**
   - 明确自己的关键词
   - 搭框架：把现阶段想分享的选题全列出来 → 做成思维导图 → 看具备哪些能力、欠缺哪些知识
   - 获取知识 → 内化实践 → 形成体系

## 三、封面

### 四条底层逻辑
| 逻辑 | 做法 |
|---|---|
| **反差对比** | BA 图（before / after） |
| **视觉冲击** | 引起好奇的标题封面（没听过的方法、没听过的工具）；冲突悬念类（反常识）；**大字报**（突出主旨、简洁明了） |
| **极具美感** | 适合颜值类 |
| **引起好奇** | 信息量大（手机备忘录截图、手写笔记）；内容丰富（拼图类）；未展示全貌 |

### 制作要点
- **宽高比**：图片建议 3:4，全账号尽量保持一致
- **工具**：海报类用 canva / 创可贴 / 高定设计；实拍类用醒图 / 黄油相机
- **整体调性统一**
- **爆款封面要重复用**，不要每次都换新花样

## 四、标题：六个公式

**硬性要求：≤20 字符，1 秒内能看懂，3 秒内能判断出笔记内容。**

| # | 公式 | 说明 | 例 |
|---|---|---|---|
| 1 | **引起好奇** | 感叹惊讶式（配吸睛封面一起用）、揭秘类 | |
| 2 | **提出疑问** | 直接疑问 / 问题+解决方案 | 我为什么从来不刷短视频？ |
| 3 | **多用数字** | **一定是阿拉伯数字**，用户一眼能看到 | 见下 |
| 4 | **方法集锦** | 针对一个痛点给多个解法，营造「立刻能解决」的轻松感 | |
| 5 | **引发共鸣** | 明确表达某个观点，带鲜明个人色彩 | |
| 6 | **锁定人群** | 标题里植入人群关键词，让目标用户刷到就对号入座 | |

数字的四种用法：
- **价格**——适合种草类；性价比高就写进标题；和看上去很贵的封面组合形成反差
- **数量**——营造很多、很全
- **时间**——营造见效快、速成
- **对比数字**——展现巨大差距

## 五、笔记结构（拆解对标时照这个框架）

图文笔记：
- **段落**：开头 / 中间 / 结尾各是什么结构？开头是讲故事、讲痛点还是讲干货？正文是并列还是递进？怎么结尾？
- **图片信息**：每张图什么画面？图上文字的逻辑结构是什么？
