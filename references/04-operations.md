# 运营：提升互动 + 数据复盘

## 一、三个互动技巧

### 1. 埋钩子
- 设置问题引导用户评论
- 设置争议话题和画面（故意设计有争议的画面）

### 2. 弹幕引导（视频）
**设置指令引导观众发弹幕**，四种模板：
| 类型 | 例 |
|---|---|
| 场景认同类 | 「总是三分钟热度、间歇性打鸡血、持续性颓废，有相同情况的请扣 1」 |
| 留言许愿类 | 「把你理想中的大学发在弹幕上许愿」「把'成功上岸'打在弹幕上」 |
| 情绪感召类 | 「想跟我一起改变的，把'我要变富'打在弹幕上」 |
| 预告提示类 | 「想看测评的扣'想看'，想看详细教程的扣 1，下次分享」 |

**自己发弹幕引导**：干货视频前 10 秒，用小号发引导收藏的弹幕——「先收藏了」「在我的收藏夹吃灰吧」

### 3. 评论区运营
- **回复用户留言**——但某些情况下**不要立即回复**（比如购买链接：一旦别人看到了，就不会再评论了）
- **用评论引起好奇**：留下强相关的问题；放在视频中间位置能提高完播率
- **在评论区增加诱饵**：把视频里讲不完整的内容放评论区，激发兴趣，引导更多人留言要后续
- **用评论引导用户访问主页**：「这是什么宝藏博主，进了主页出不来了」
- 新笔记发布后，**在之前的爆款笔记里置顶引导**，把老流量导到新笔记和主页

## 二、发布前自检清单

**选题**
- [ ] 推到陌生人面前时，他会觉得与我有关吗？
- [ ] 这篇笔记想让用户获得哪方面的价值？

**封面 & 标题**
- [ ] 封面能被一眼看到吗？能激起点击欲望吗？
- [ ] 标题是否超过 20 字符？
- [ ] 标题 1 秒内能看懂吗？3 秒内能判断出笔记内容吗？

**整体内容**
- [ ] 文案通俗易懂吗？
- [ ] 图片有没有其他网站或二维码？（违规）
- [ ] 希望用户看完有哪些互动行为？这篇笔记能触发吗？
- [ ] 植入关键词了吗？
- [ ] 文末有话题标签吗？

**视频额外项**
- [ ] 气口剪掉了吗？
- [ ] 字幕有没有错别字？
- [ ] 背景音乐盖住人声了吗？
- [ ] 戴耳机听：自己的和别人的声音大小是否一致？
- [ ] 屏幕里有没有出现其他平台的名字或痕迹？

**爆款因子**
- [ ] 有 3 个以上爆款因子吗？
- [ ] 选题、封面、标题里各有没有爆款因子？

## 三、发布后自检

1. **检查审查状态**——用另一个小红书账号打开，看笔记在不在
2. **检查收录状态**——搜关键词，能不能出现在搜索结果页
   - 未收录常见原因：敏感词、涉嫌违规（可咨询客服）
3. **检查关键词**——**判断算法怎么理解你这篇笔记**
   - 电脑浏览器打开笔记 → 右键 → 显示网页源代码
   - 找 `meta name="keywords" content="..."`
   - 里面的词就是算法判定的关键词，系统会把笔记推给对这些词感兴趣的人
   - **如果和你想要的人群不符，说明关键词植入失败，下次要改**
4. **检查是否违规**——阅读量低于 100 或一直卡在 100 左右，可能涉嫌违规
   - 申诉路径：主页左上角 → 帮助与客服 → 笔记申诉 → 选择笔记 → 选择「流量不好/搜不到」

## 四、单篇笔记复盘表

### 记录数据 → 分析原因 → 总结经验

| 数据 | 说明什么 | 不理想时怎么查 |
|---|---|---|
| **阅读量** | 有没有人点 | 没人点 = 对封面、标题不感兴趣。① 分析选题角度是不是用户感兴趣的（同类选题别人怎么写？切入角度是什么？戳中了痛点/爽点/痒点？）② 和爆款笔记对比封面元素、标题关键词 |
| **点赞 vs 收藏** | 内容质量是否被认可 | **点赞>收藏** = 情绪价值高；**收藏>点赞** = 使用属性强，一般会有持续流量，但周期不确定 |
| **阅读:点赞** | 内容质量硬指标 | **10:1** 基本能成爆款 / **10:1~20:1** 流量会涨但不明显 / **30:1** 普通笔记、低价值 |
| **评论数** | 用户还有什么没被满足 | 分析共性问题，总结答案，下次直接写进笔记 |
| **涨粉数** | 是否达成目的 | 发布前就要定这篇的目的：博爆款？圈流量？强化人设？按目的复盘 |

**阅读:点赞比不达标时，四个切入点**（与同选题的爆款对比）：
- 有没有传递情绪价值和内容价值？
- 有没有 3 个以上爆款因子？
- 有没有戳中痛点？
- 有没有收藏价值？

**输出三件事**：经验清单 / 问题清单 / 下一步改进计划

## 五、账号级复盘（每周 / 每月）

| 维度 | 怎么复盘 |
|---|---|
| **发布数** | 设定发布指标 → 对比实际 vs 计划 → 检查工作流程和选题布局 |
| **点赞 & 收藏** | ① 筛同领域近期爆款：细分方向、切入角度、共性、评论区讨论、标题关键词 ② 分析自己的爆款：流量密码是什么？哪些可复用？数据差的笔记差在哪？ |
| **涨粉数** | 下降 = 个人特色不够，加强人设 |

**制定生死线**：设定爆款指标和扑街指标（扑街 = 远低于平时）。

## 六、建立数据监测系统

- 固定发布时间，记录发布后的数据
- 积累多次之后：
  - 能**预判**同类型笔记会不会成爆款
  - 数据差距大时，通过对比判断内容好坏——差的找差距，好的找爆款因子并复用
