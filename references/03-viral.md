# 爆款与涨粉

## 一、推荐机制：七个互动数据

平台推不推你，只看互动数据。每个数据对应一个可控动作：

| 数据 | 决定什么 | 怎么提 |
|---|---|---|
| **点击率**（点击数/曝光量） | 用户对内容感不感兴趣 | **选题受众要广**（符合大多数人的核心利益）+ **标题封面要与用户有关** |
| **点赞数** | 情绪波动 | 让用户「感到喜欢 / 感到美好 / 感到惊艳」 |
| **收藏数** | 有没有用 | 攻略类、教程类、合集类；加入清单、攻略、使用方法 |
| **评论数、弹幕数** | 互动值 | 见 `04-operations.md` 的埋钩子 |
| **完播率** | 内容有没有层次 | 镜头感、观众缘；脚本有节奏感、引起好奇；画面清晰 |
| **转发数** | 社交属性 | 情感共鸣 / 社交货币 / 行动指令 |
| **关注数** | 转粉 | 见本文涨粉公式 |

**选题受众要广**的典型对比：
「30 岁生日 vlog」（只有你自己关心）vs「30 岁财务自由，关于财富的 3 点认知」（所有人关心）

## 二、三个技巧：痛点、痒点、爽点

### 痛点 = 目标用户害怕、恐惧、焦虑、不安、愤怒的点
**操作：先按场景分类，在每个场景里罗列痛点，再归到下面五类：**

| 类别 | 细分 | 例 |
|---|---|---|
| **与钱有关** | 免费资源、平价薅羊毛 | 选校信息网 |
| **走捷径** | 省时 / 省力 / 短期速成 | 3 分钟 xxx |
| **比较** | 替用户说出焦虑 → 基于焦虑给解法 | |
| **羡慕** | 晒优于常人的能力（晒成绩、晒物品）→ 给出方法 | |
| **宣泄情绪** | 替用户宣泄 / 阻止用户宣泄 | |

### 痒点 = 用户希望实现的愿望
关键是**让用户看到结果**：
- 「我做不到，但看你做到了很满足」
- 「我想做到，看到你做到了就想象自己也能」

### 爽点 = 短时间内被满足的需求
特点：传播广、调动情绪。
方法：**替用户说话**（说出他想表达的）、**释放用户情绪**（娱乐、情感类）

## 三、两个方法

### 方法一：追热点

**热点** = 特定时间内很多人关注和讨论的事。**先判断和自己账号定位匹不匹配。**

两个能力：
- **有网感**——什么热点适合自己
  - 训练法：去目标用户多的地方，看他们在讨论什么
  - 看对标的爆款笔记：用户在讨论什么？发什么弹幕？哪些关键词？
- **会迁移**——从创作者视角审视
  - 这个热点戳中了哪些痛点？释放了哪些情绪？
  - 这个关键词能不能迁移到我的领域？
  - 我的受众是否也关心？

**三类热点：**
| 类型 | 做法 |
|---|---|
| **限时热点**（热点事件/现象、热点人物） | 短期求快（信息类、情绪类选题，立刻写立刻发）→ 中期求优质 → 后期求差异性 |
| **日常热点**（可预判） | 节假日（参考历年爆款）、可预判大事件（提前收资料写好稿）、固定节点（618、双 11） |
| **热点活动** | 小红书官方活动（有流量扶持）、笔记灵感里的话题 |

### 方法二：成倍增加内容价值

爆款的核心只有一个问题：**能不能带来价值。**

| 价值类型 | 细分 |
|---|---|
| **情绪价值**（看完舒适、快乐、激动） | 励志、慕强、治愈 |
| **内容价值 · 实用** | 攻略、合集、教程——以解决某个问题为目的，用通俗易懂的方式给解法 |
| **内容价值 · 新知** | 别处看不到的东西。两种体现：**主题稀缺**（在英国讲历史）、**方法新颖**（信息差） |

## 四、三类爆款笔记模板

| 类型 | 特点 | 常见切法 |
|---|---|---|
| **合集类** | 内容丰富、信息量大、全面 | 按人群 / 按价格 / 按地域 / 按时间 / 按场景 / 按用户需求或产品功能（如「美白」「美白 + 痛点关键词」） |
| **颜值类** | 美好的生活 / 物品 / 人 | |
| **省时类** | 帮用户省时间 | **测评类**（产品卖点、适用人群，客观公正）/ **攻略类**（从 0 到 1 解决问题）/ **教程类**（使用步骤、适合人群和场景） |

## 五、爆款因子：发布前数一数

**爆款因子清单**（每篇笔记至少凑齐 3 个）：
- 需求点：痛点 / 痒点 / 爽点
- 笔记：吸睛封面 / 吸睛标题
- 价值：情绪价值 / 内容价值
- 形式：工具 / 清单 / 合集

**成倍放大的四种做法：**
1. 极具冲击力的封面和标题
2. 极度夸张的情绪
3. 极度稀缺的干货
4. 互动性极强的评论区

## 六、涨粉公式

```
涨粉数 = 阅读量 × 转粉率
转粉率 = 内容优质 + 人设鲜明
关注动机 = 长期有用 + 提供稀缺
```

**转粉率 = 涨粉人数 / 阅读量。** 核心是：给打开笔记的人一个必须关注你的理由。

| 变量 | 怎么做 |
|---|---|
| **内容优质** | 角度新颖 / 呈现形式独特 / 干货更多 / 更容易落地 |
| **人设鲜明** | 鲜明的个人标签 / 强调努力的过程 / 强化语言风格 |
| **长期有用** | 让用户相信你能持续提供有价值的内容 |
| **稀缺** | 标签稀缺（经历、职业、身份、性格）/ 颜值稀缺 / 内容稀缺（某类内容只有你能发） |

## 七、按用户路径优化

| 阶段 | 优化什么 |
|---|---|
| **打开笔记前** | 爆款标题、封面——这两个决定阅读量 |
| **浏览笔记时** | 个人特色：有趣、有价值、不同；突出人设和记忆点 |
| **进入主页后** | ① 视觉风格统一 ② 简介让人快速了解定位/方向/预期 ③ 内容质量稳定在市场及格线以上 ④ **持续、稳定、高频更新** |
