# 变现

四条路：广告、知识、带货、影响力。新号的顺序通常是：影响力 → 广告 → 知识/带货。

## 一、广告变现

### 合作形式

**置换合作**（新手起步）
- 博主免费获得品牌方产品，使用后发「种草」体验笔记
- 价值：积累案例 + 锻炼商务沟通和商单创作能力
- 怎么接到：品牌方主动联系 / 小红书「好物体验」功能 / 第三方平台（螃蟹通告）/ 通告群

**付费合作**
- **报备合作**：开通蒲公英（粉丝 >1000，平台抽成 10%）
- **不报备合作**：广告植入太明显可能被判违规

### 呈现形式与单价
图文单推 / 图文合集 / 视频单推 / 视频合集
**单价：单推 > 合集；视频 > 图文**
合集 = 一篇笔记围绕一个主题介绍多个产品，其中一个环节植入广告，单价较低。

### 报价

**基础公式：报价 = 粉丝数 × 10%**

影响报价的六个因素：
| 因素 | 说明 |
|---|---|
| 呈现形式 | 单推 > 合集；视频 > 图文 |
| 粉丝数 | 基础盘 |
| **近期数据** | 重点看**近 10 篇笔记的点赞数和阅读数**；高粘性、高互动、高爆款可提价 |
| 领域 | 报价前三：护肤、母婴、美食饮品 |
| 品牌方预算 | |
| 账号调性 / 品牌契合度 | |

数据参考工具：千瓜数据、千红

### 两个注意事项
1. **珍惜羽毛**——接之前搜一下有没有别的博主介绍过，调研产品本身
2. **高效沟通**——建合作 SOP，细节一次性沟通清楚

### 怎么源源不断收到合作

**品牌方喜欢什么样的账号：**
- **定位垂直**——内容垂直，粉丝和品牌受众一致；**品牌调性和粉丝消费能力要匹配**
- **有植入空间**——内容形式里得有广告位
- **数据好**——近期出爆款的频率高 + 粉丝数
- **有附加价值**——比如你的素材品牌方能拿去别的渠道用

**主动被找到的两个动作：**
1. **露出广告位**——让品牌方看到你的内容能放广告
2. **添加关键词**（投放逻辑：品牌方搜和竞品相关的关键词，找这些博主投放）
   - 找同选题的爆款笔记，看它加了哪些热门话题标签
   - 按第三方数据榜单，按领域搜近期热词
   - 做同领域的选题
   - **加竞品的关键词**

## 二、知识变现（被动收入的主路）

### 为什么小红书适合
- 主要用户是年轻女性，**付费意愿强**
- 倒逼你形成自己的知识体系
- 和用户形成深度链接，有口碑效应

### 怎么开通专栏
1. 申请开通——关注账号「专栏成长学院」看最新申请方法
2. 查看是否开通——创作中心 → 创作服务 → 主播中心
3. 创建课程——专栏 → 创建专栏

### 普通人的三步
1. **搜索信息，找到需求**——罗列具体问题 → 归纳成核心痛点
2. **整理知识，提出解决方案**
3. **系统输出，实际交付**——直播课 / 录播课

## 三、带货变现

| 方式 | 门槛 | 要点 |
|---|---|---|
| **直播带货** | 实名认证 + 开通专业号 | 渠道：选品中心带货（粉丝 >1000）、自营专栏、店铺带货 |
| **小清单带货** | 粉丝 >1000 | 选品中心 → 选商品 → 去带货 → 小清单带货 → 创建；填简介、选商品、写 10–30 字推荐理由。引导：个人简介标注「首页搜索 xxx 的小清单」；笔记正文和评论区放同款 |
| **店铺带货（号店一体）** | 实名 + 专业号升级 + 押金（个人号 1000） | 抽成：一万以下不抽成，7 天结算到账。开通：创作中心 → 更多服务 → 内容变现 → 店铺 |

## 四、影响力变现

用小红书曝光产品，把用户引到其他平台成交。
核心：**输出垂直领域内容 → 吸引精准人群 → 放大个人品牌价值**

⚠️ 这条路直接撞平台的站外引流红线，操作方式见 `07-platform-rules.md`。
