# 长期能力：三大能力 + 四个思维

## 三大能力

### 一、拆解力（最重要，所有起号动作的地基）

**拆解一篇对标笔记的完整流程：**

1. **记录基本信息**

2. **拆笔记外观**
   - 看到这篇笔记，你的第一反应是什么？
   - 标题里哪些关键词吸引了你？
   - 哪些元素促使你打开？

3. **拆笔记框架**
   - **图文**：
     - 段落——开头/中间/结尾各是什么结构？开头讲故事、讲痛点还是讲干货？正文并列还是递进？怎么结尾？
     - 图片——每张什么画面？图上文字的逻辑结构是什么？
   - **口播**：提取文案
   - **视频**：截图、看构图

4. **拆互动行为**
   - 用户在议论什么？（选题本身？某个观点？某个工具/方法？）
   - 出现最多的关键词是什么？
   - 在表达什么情绪？
   - 有没有没被解答的疑惑？（**这就是你的选题**）

5. **拆爆款因子**

6. **整理可复用的点**

### 二、系统力

- **大量阅读，系统输入**——刻意搭建选题库
- **吸收内化，实践输出**——一边输入一边输出
- **形成自己的知识库**——用**卡片笔记法**：碎片时间输入的内容做成一条条卡片，积累到一定量后按逻辑重新排列组合

### 三、内驱力

- 找到初始动力
- 找到对标人物和账号

## 四个思维

### 1. 鲁莽思维：立刻去做
行动 → 做出微小的成绩 → 输出。
**万物皆有信息差**——你觉得人人都知道的事，其实大部分人不知道。

### 2. 用户思维：极致利他

两个关键问题：
- 你的内容是不是用户想看的？
- 你的内容是不是对别人有用的？

**三阶段 SOP：**

**写作前，代入用户视角**
- 这个话题是你关心的吗？
- 这个封面你想不想点击？
- 这个角度与你有关吗？

**写作时，假装在跟小学生聊天**
- 把用户当小白，迎合小白的知识水平

**写作后，过一份自查清单**
- 写这篇笔记的目的是什么？
  - 目标用户是谁？
  - 想解决用户什么问题？
  - 用户的需求是什么？需要哪方面的信息？
  - 什么内容能让他们感兴趣？
  - 要达到什么目标？如何衡量？
- 希望用户做出什么反应？
  - **点赞** → 激发情绪价值
  - **收藏** → 提供内容价值
  - **评论** → 存在讨论点、争议点
- 内容是否通俗易懂？
  - 这篇笔记的知识水平如何？
  - 是否契合用户的理解水平？
  - 是否足够通俗易懂？

### 3. 作品思维：用自媒体放大个人品牌价值
- 精心打磨每一篇笔记
- 用笔记放大个人价值

### 4. 长期主义：不下牌桌
- **用长期主义设定目标**——不必在意一城一池的得失，以季度、年度为单位做内容
- **用长期主义看数据**——专注内容本身，只和自己比较
- **用长期主义做内容**

## 日常工作流（循环）

```
内容检索 → 进入灵感库 → 细分选题 → 主题策划 → 是否选题 → 内容撰写 → 数据追踪 → 回到内容检索
```
