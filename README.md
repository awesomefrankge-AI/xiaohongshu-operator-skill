# 小红书运营 Skill

> 一套能直接执行的小红书方法论，装进 Claude 就能用。
> 不是「多发优质内容」这种废话，是**可以照着做的公式、清单和诊断表**。

---

## 这个 skill 能替你做什么

| 你说 | 它会做 |
|---|---|
| 「帮我给做 AI 增长的号定个位」 | 按「变现方式 + 人群 + 需求」推导出一句话定位，给人设三件套和主页简介 |
| 「给我 10 个选题」 | 用长尾词裂变 / 交叉组合 / 评论区挖掘，给具体选题，不是给方法论 |
| 「这个标题行不行」 | 对照 6 个标题公式和 20 字符硬线改写，给 5 个备选 |
| 「这篇笔记数据不好，帮我看」 | 先判断是阅读量问题还是转粉率问题，按阅读:点赞比定级，给出具体改哪里 |
| 「怎么涨粉」 | 拆成阅读量 × 转粉率两个变量分别诊断，不给笼统建议 |
| 「我 5000 粉，这条广告报多少」 | 按报价公式算基准，再按形式、近 10 篇数据、领域调整 |
| 「帮我拆这个对标账号」 | 按 6 步拆解法：外观 → 框架 → 互动 → 爆款因子 → 可复用点 |
| 「我想引流到微信」 | 先过红线检查，给 4 种合规做法（按风险排序） |

## 核心 knowhow 速览

下面是 skill 里最硬的几块。**全文在 `references/`，这里只放能一眼带走的。**

### 1. 定位不是「我想做什么」，是「谁会因为什么关注我，我靠什么赚钱」

```
商业模式定位 = 变现方式 + 人群 + 需求
```
**先定变现方式，再倒推内容。顺序反了就是自嗨号。**

赛道三问，**任何一个不过就淘汰**：
- **赚钱**：品牌投放这个赛道吗？其他博主怎么接广告？
- **喜欢**：有没有内驱力持续输出？
- **擅长**：**能不能当场列出 10 个以上选题？** ← 列不出来的赛道，直接放弃

人设靠三件事立住：**特征**（你是什么样的人）+ **身份**（职业身份 / 角色身份）+ **场景**（反复出现的环境）。
强化手段：语言风格、内容调性、**固定开头和固定结尾话术**、环境强化。

### 2. 爆款不是灵感，是因子叠加

**爆款因子清单——每篇笔记至少凑齐 3 个，少于 3 个不发：**

| 类别 | 因子 |
|---|---|
| 需求点 | 痛点 / 痒点 / 爽点 |
| 笔记 | 吸睛封面 / 吸睛标题 |
| 价值 | 情绪价值 / 内容价值 |
| 形式 | 工具 / 清单 / 合集 |

**痛点的五个母题**（罗列场景痛点后往这五类归）：
与钱有关（免费、薅羊毛）· 走捷径（省时、省力、速成）· 比较（替用户说出焦虑 → 给解法）· 羡慕（晒成绩/晒物 → 给方法）· 宣泄情绪（替用户宣泄 / 阻止用户宣泄）

**选题受众要广**，看这组对比就懂：
❌「30 岁生日 vlog」——只有你自己关心
✅「30 岁财务自由，关于财富的 3 点认知」——所有人关心

### 3. 涨粉是个乘法，不是加法

```
涨粉数 = 阅读量 × 转粉率
转粉率 = 内容优质 + 人设鲜明
关注动机 = 长期有用 + 提供稀缺
```

数据差的时候**先分清是哪个变量出问题**：
- 阅读量低 → 选题 / 封面 / 标题的问题
- 阅读量正常但不涨粉 → 内容不够优质，或人设没有记忆点

「稀缺」的四种来源：标签稀缺（经历、职业、身份、性格）· 颜值稀缺 · 内容稀缺（某类内容只有你能发）

### 4. 一条笔记值不值，看阅读:点赞比

| 比值 | 判定 |
|---|---|
| **10:1** | 基本可以成为爆款 |
| 10:1 ~ 20:1 | 流量会涨，但不明显 |
| **30:1** | 普通笔记，低价值 |

还有一条：**点赞 > 收藏 = 情绪价值高；收藏 > 点赞 = 使用属性强**（后者会有持续流量，但周期不确定）。

### 5. 标题六公式（硬线：≤20 字符，1 秒看懂）

1. **引起好奇**——感叹惊讶式、揭秘类
2. **提出疑问**——「我为什么从来不刷短视频？」
3. **多用数字**——**必须是阿拉伯数字**。四种用法：价格（性价比反差）· 数量（营造很全）· 时间（营造速成）· 对比数字（展现差距）
4. **方法集锦**——一个痛点给多个解法，营造「立刻能解决」
5. **引发共鸣**——明确表达观点，带个人色彩
6. **锁定人群**——标题里植入人群词，让目标用户对号入座

### 6. 六种选题法（起号先用第 1 和第 2）

| 方法 | 一句话 |
|---|---|
| **对标账号法** | 找 1–3 个对标 → 筛点赞前十 → 分类汇总成选题库 |
| **长尾词裂变法** | 搜大词看下拉框，那些词是系统按真实搜索行为匹配的；再叠加「场景 × 人群 × 事物」 |
| **评论区法** | 看对标爆款评论区——**用户看完还有什么疑问，那就是你的下一篇** |
| **热点法** | 小红书 → 创作中心 → 笔记灵感（每周必看）。限时热点求快，日常热点提前备稿 |
| **交叉法** | 领域 × 内容形式 × 时间 × 人群 × 价格，组合出选题 |
| **系列法** | 固定栏目 / 固定时间 / 系列专题 |

### 7. 发布前自检（节选，完整版在 `04`）

- [ ] 推到陌生人面前，他会觉得**与我有关**吗？
- [ ] 标题超过 20 字符了吗？1 秒能看懂吗？
- [ ] 图片里有没有二维码、微信号、其他平台名称？（**最常见的限流原因**）
- [ ] 有 3 个以上爆款因子吗？
- [ ] 希望用户点赞、收藏还是评论？这篇笔记能触发吗？

### 8. 发布后必做的一件事：查算法给你打了什么标签

```
电脑浏览器打开笔记 → 右键 → 显示网页源代码 → 找 meta name="keywords"
```
里面的词就是**算法判定的关键词**，系统按这些词推人。和你想要的人群不符，说明关键词植入失败。

### 9. 广告报价

```
基准报价 = 粉丝数 × 10%
```
六个调整因子：呈现形式（单推 > 合集；视频 > 图文）· 粉丝数 · **近 10 篇的点赞和阅读**（最关键）· 领域（报价前三：护肤、母婴、美食饮品）· 品牌预算 · 调性契合度。

**品牌方只关心两件事**：你垂不垂直、你的粉丝和他的目标用户匹不匹配。

### 10. 站外引流的四种合规做法（风险从低到高）

平台明令禁止水印、微信号、二维码。留的缝：
1. **主页简介**用文字描述（「公众号同名」），不放码
2. **私信关键词**——笔记引导「私信回复 xxx」
3. **评论区**——用户主动问了再回，不要自己置顶
4. **优先站内承接**——专栏、小清单、店铺，风险最低
